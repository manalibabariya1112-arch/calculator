# 🧮 Calculator Using Java

## 📌 Project Overview
The Calculator is a console-based application developed using Java as part of **Internship Task 2 at Next Gen Software Hub Pvt. Ltd.**

This application performs basic arithmetic operations and provides a simple way for users to perform mathematical calculations through the console.

## 🎯 Objectives
- To understand the fundamentals of Java programming.
- To implement basic arithmetic operations.
- To practice conditional statements and user input handling.
- To improve logical thinking and problem-solving skills.

## ✨ Features
- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- ⌨️ User input through the console
- 🖥️ Simple and easy-to-use interface

 ## 🛠️ Technologies Used

 - **Programming Language:** Java

 - **Application Type:** Console-Based Application

 - **IDE:** IntelliJ IDEA

## ⚙️ How to Run the Project

# Prerequisites

  -Install the Java Development Kit (JDK).

  -Install IntelliJ IDEA.

### Steps
1. Clone this repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Open the project folder in VS Code.
3. Open the Java source file.
4. Compile the program:

   ```bash
   javac Calculator.java
   ```

5. Run the program:

   ```bash
   java Calculator
   ```

**Note:** Replace `Calculator.java` and `Calculator` with your actual Java filename and class name if they are different.
